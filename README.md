# RTS 卡牌游戏 · Phaser 4 引擎原型

> 本文档是给**接手开发的 AI / 开发者**的完整交接说明，重点讲清楚三件事：
> **长枪兵是怎么用代码画出来的**、**动作系统是怎么工作的**、**对战测试（长枪兵 vs 剑士）的规则与实现**。

## 一、项目概况

- **目标**：基于 Phaser 4 的卡牌驱动 RTS 游戏（皇室战争类：出牌召唤单位，自动战斗）
- **当前进度**：
  - 两个兵种：暗影长枪兵（A 方，绿）和 剑士（A 方，绿），**同一阵营**，不互相攻击
  - **单位生成**：从屏幕左边统一生成，生成位置一致
  - **框选系统**：支持左键拖拽框选多个单位，批量控制
  - **边界限制**：单位底部边界是卡牌栏，不会进入卡牌栏区域
  - **木质质感底部卡牌栏**：深色实木底板 + 木纹纹理 + 金属装饰条 + 铆钉 + 皮革内衬凹槽
  - 伪3D 叠加：单位不做纯 2D 边界碰撞，按 y 深度排序允许叠加覆盖（靠下=更近=画在上层）
  - 软分离：同队单位过近时自动缓慢隔开一点点距离，避免完全重叠
  - **长矛兵：攻击距离长（枪尖刚碰到敌人就出伤）+ 命中击退 + 首击 50% 暴击 + 贴脸后撤步**
  - **剑士：移速快 / 攻击高 / 血厚 / 对长枪兵 1.5 倍伤害加成 / 30% 盾牌格挡（格挡弹开长枪）**
  - 单位控制：V 立即停止攻击／A 重新攻击／右键立刻停战移动／K 处决单位
  - **批量控制**：框选多个单位后，V/A/K 键可以控制所有选中单位
  - 兵种数据驱动：`src/units.ts` 注册表，加新兵种不用改场景逻辑
- **技术栈**：Vite 6 + TypeScript + Phaser 4.0.0
- **美术策略**：全部用代码绘制（曾尝试 AI 出图，一致性差，已废弃并清理）

## 四、核心：长枪兵是如何渲染的（src/art/spearman.ts）

### 4.1 坐标系约定（最重要）

- 每个单位的 `Graphics` 对象锚在**脚底点**，局部坐标 `(0,0) = 脚底`，绘制方向**向上 = y 为负**
- 世界坐标：`gfx.setPosition(pos.x, pos.y)`，局部 `(0,0)` 即脚底世界位置
- 身体尺寸参考：躯干中心 `(0, -30)`、头中心 `(0, -63)`、手 `(9, -28)`、枪全长 172px、枪尖最高可到 y ≈ -190

### 4.2 画布变换（整个动画系统的地基）

`Graphics` 支持画布变换栈，`drawSpearman` 用它实现**镜像、弹跳、旋转**：

```ts
g.save();
g.translateCanvas(xShift, bob);   // 水平位移（突进/击退）+ 竖直弹跳
g.scaleCanvas(flip, 1);           // 朝向镜像（flip = 1 朝右，-1 朝左）
g.rotateCanvas(rot);              // 整体旋转，绕脚底点 → 攻击前倾 / 死亡倒下
// …… 在此变换内绘制全部身体部件（都按"朝右"的局部坐标写）……
g.restore();
```

要点：
- **朝向翻转不用逐点镜像坐标**，`scaleCanvas(flip,1)` 一行搞定，绘制代码永远按"朝右"写
- **死亡倒下 = `rotateCanvas` 从 0 转到 -1.28 弧度**（绕脚底旋转，像树倒下），整幅画（含长枪）一起转
- 地面阴影画在变换**外面**（不跟着旋转/镜像）
- 受击闪白 = 所有颜色向白色插值（`mix()` 函数）

### 4.3 绘制顺序与调色板

```
地面阴影 → 腿 → 躯干(椭圆+胸腹凸起+高光+腰带) → 披风(上窄下宽梯形) → 前护肩
→ 大头(圆形+描边) → 头盔(兜帽全遮面) → 发光单眼 → 手臂 → 长枪(黑色杆+菱形枪头) → 手
```

| 颜色 | 值 | 用途 |
|---|---|---|
| 铠甲主体 | `0x1f232a` | 躯干 |
| 铠甲高光 | `0x2a2f38` | 胸甲前侧 |
| 描边 | `0x0a0c10` | 轮廓线 |
| 头盔/兜帽 | `0x14171d` | 头部遮盖 |
| 披风 | `0x10141a` / `0x1e232b` | 深色双层 |
| 枪杆 | `0x14171c`（黑） | 长枪 |
| 枪头 | `0xd0d6de`（银）+ 暗色描边层 | 菱形 |
| 眼 | `0x3fe0c0`（青，可配） | 发光单眼 |

### 4.4 两个核心接口

```ts
// 外观配置：决定"长什么样"
interface SpearmanConfig {
  bodyW: number; bodyH: number; headR: number;
  helmet: 'crest' | 'horn' | 'plume' | 'visor' | 'hood';
  cape: 'long' | 'short' | 'ragged' | 'draped';
  accent: number;          // 眼睛/装饰色
  fullHood?: boolean;      // 兜帽全遮面，只留一只眼
  spearLen?: number;       // 枪长，默认 172
}

// 动画参数：决定"怎么动"（每帧传入）
interface SpearmanAnim {
  flip?: 1 | -1;      // 朝向
  bob?: number;        // 竖直弹跳
  rot?: number;        // 整体旋转（弧度）
  xShift?: number;     // 水平位移
  legSwing?: number;   // 腿摆动（|值|>0.12 时画两条腿一前一后，否则一条腿）
  legLift?: number;    // 抬腿
  spearLean?: number;  // 枪前倾角（弧度，0=竖直，~1.5=放平）
  spearExtend?: number;// 枪伸长
  grip?: number;       // ★ 手到枪尾距离：回缩变大、刺出变小（滑枪）
  capeSway?: number;   // 披风下摆摆动
  flash?: number;      // 受击闪白 0..1
  eyeGlow?: number;    // 眼睛发光强度
}

export const SPEARMAN_FINAL: SpearmanConfig = { bodyW: 18, bodyH: 48, headR: 16,
  helmet: 'hood', cape: 'draped', accent: 0x3fe0c0, fullHood: true, spearLen: 172 };
```

## 五、核心：动作系统（src/DemoScene.ts）

### 5.1 两层状态机

```ts
// 视觉层：决定播放哪套动作曲线
anim.mode: 'idle' | 'walk' | 'hurt' | 'die'

// 战斗层：决定战斗姿态（所有近战兵种通用）
combat.phase: 'none' | 'level' | 'stab' | 'recover'
```

**状态机流转**：`walk`（移动中）↔ `idle`（停下）→ 受击进 `hurt`（0.28s 后回）→ 死亡进 `die`（播完删除）。
战斗层：`orderAttack()` 进入 `level` → `stab` 循环 → 脱离战斗（右键打断/目标全灭）进 `recover` → `none`。

**索敌**：双方兵种每帧检查 `nearestEnemyInRange(u, u.stats.aggro)`，召唤出来即自动参战；目标死亡后自动换最近敌人，全灭则收武器待机。
**停止（V 键）**：`u.holdFire = true` 挂起自动索敌，单位停止攻击站桩；A 攻击 / 右键移动指令解除挂起。

### 5.2 各动作的参数曲线

| 动作 | 参数曲线 |
|---|---|
| **idle** | `bob = sin(t*2.2)*0.9` 呼吸、`rot = sin(t*1.6)*0.015`、`eyeGlow = 1+0.15*sin(t*3)` 光晕 |
| **walk** | `bob = -abs(sin(p))*3.5` 弹跳、`rot = sin(p)*0.05`、`legSwing = sin(p)`（两条腿一前一后）、`capeSway = sin(p)*2.5` |
| **attack** | 见下方战斗算法 |
| **hurt** | `rot = -0.09*(1-t/0.28)` 后仰 + 受击闪白（`flash=0.18` 快速衰减） |
| **die** | 后仰(0.15s) → `rot` 转到 -1.28 倒下(0.55s) → 着地微弹(0.15s)+尘土 → 淡出(0.45s) |

### 5.3 战斗算法（本项目的核心难点，已解决）

**原则：攻击距离由枪尖的几何位置决定，不是拍脑袋的常数。**

```
放平枪 level (0.28s)：枪从竖直(lean 0.17)压向瞄准角
突刺循环 stab（每周期 0.42s）：
  0~0.18s 回缩：grip 30→50（枪尾后探、枪尖回收），身体微退 xShift -3
  0.18~0.33s 刺出：grip 50→14（枪向前滑出），身体前冲 xShift +9，眼睛骤亮
  0.28s    伤害结算（此刻 grip=26，枪尖长度恰好 146px）
  0.33~0.42s 停顿保持
收枪 recover (0.65s)：枪慢慢收回竖直位（记录 lastLean 插值回去）
```

**枪尖瞄准算法（两个关键函数）**：

```ts
// 1) 距离控制：以"手→目标中心"为基准
//    长枪兵：理想值 = 枪尖长度 tipAtHit(146)，不刺入（枪尖碰到敌人就结算伤害）
//    剑士：  理想值 = 剑尖(37) − 刺入深度(8) = 29px
//    太远(> 理想+6)前进；太近时**长枪兵不后退**（判定为射程内继续刺），只有剑士后退
keepRange(u, t, dt)

// 2) 瞄准：每帧由"手→目标中心"方向实时求枪的前倾角
//    目标矮 → 压枪向下；目标高 → 抬枪。枪尖永远指向目标中心
spearAimLean(u, t) = Clamp(atan2(dx/d, -dy/d), 0.2, 2.0)
```

**换新单位时**：近战武器只要定义"握持点 + 武器长度"，距离控制和瞄准自动生效。

**长枪兵特性：枪尖接触伤害 + 击退 + 首击概率暴击 + 贴脸后撤步**

```
伤害结算(0.28s)时，枪尖长度 = tipAtHit(146px)
长枪兵交战距离 = 枪尖长度（146px，枪尖刚碰到敌人就产生伤害，不刺入身体）
击退量 push = Clamp(146 − 当前"手→目标中心"距离, KNOCKBACK_MIN=4, KNOCKBACK_MAX=10)
方向 = "攻击者→目标"连线方向
首击：第一次枪尖接触目标时 50% 概率暴击（伤害 × CRIT_MULT=3），否则为普通伤害
```

- **伤害距离**：长枪兵不刺入（`ideal = tipAtHit`），敌人刚进枪尖射程（146px）就结算伤害，
  不是等刺到身体一半才出伤；剑士才保留刺入深度（`ideal = tipAtHit − 8`）
- **击退**：命中后敌人被顶回枪尖方向 4~10px（上限防止贴身时被打飞太远）
- **首击 50% 暴击**：换目标后下一次枪尖接触掷 50% 概率暴击（大号橙色伤害数字 +「暴击!」飘字），
  否则普通伤害；无论是否暴击，首击都算已出
- **不能近战（贴脸 → 后撤步 + 站桩）**：敌人进入**它自己的攻击范围**（如剑士攻击带外沿 ≈35px）即视为"贴脸" →
  长枪兵**不连续后退**：先发动**后撤步**（一次性快速后退 ≈115px，10s 冷却，只触发一次）→ 收枪恢复 → 站着挨打；
  敌人退出攻击范围才重新出枪。（旧版"被近身持续自动后退"会造成剑士追击时在距离带边缘来回震荡"发抖"，
  已改为后撤步一次性拉开；approach 阶段同样不倒退，否则会被更快的剑士一路追着打）

### 5.6 剑士：剑盾组合 + 至上而下挥砍 + 盾牌格挡

**① 重新建模（`src/art/swordsman.ts`）**

- **希腊式全覆盖头盔**：头盔就是整个头的形状——头骨圆盔 + 前部颊甲 + T 形眼缝（缝内透出发光独眼）+ 鼻梁条 + 顶饰马鬃（accent 色）
- **无披风**；左手持**圆盾**（深色铁面 + accent 描边 + 圆钉 + 中央凸起），护在**胸口高度**；格挡时举起护住头脸
- **长剑在远侧，被身体和盾牌遮住**：绘制顺序 = 剑（最底）→ 身体 → 头 → 盾牌（最前）。侧面看剑柄被盾牌挡住、剑身中段被身体/头盔挡住，只有超出轮廓的剑尖部分露出来；待机时剑近乎竖直藏在身后，攻击时挥砍弧线从身后扫出

**② 攻击动作 = 至上而下挥砍（与长枪兵的滑枪刺击完全不同）**

```
level (0.28s)：剑从待机角(0.38)举到蓄力角(-0.85)，手抬起（handLift 0→1）
突刺循环 stab（复用 0.42s 周期）：
  0~0.18s   举剑蓄力保持（剑尖朝上偏后，手举过头顶）
  0.18~0.28s 挥砍下落：剑从 -0.85 扫到瞄准角（命中时刻剑恰好指向目标，手落下）
  0.28s     伤害结算
  0.28~0.33s 顺势下劈（跟手，剑扫到 aim+0.45）
  0.33~0.42s 保持下劈收势
```

关键：挥砍由 `handLift`（抬手上举）+ `weaponLean`（举剑角→目标角）两条曲线驱动，剑尖走一条大弧线「举过头顶 → 劈到目标 → 劈到低处」。

**③ 盾牌格挡（30%）**

- 剑士被攻击（长枪兵刺击）时掷 30% 概率：挡住 → 不扣血、不进受击、不被击退，盾牌 0.1s 举起护住头脸（`shieldBlock` 曲线）+ 盾面火花 + 「格挡」飘字
- **格挡后长枪兵的长枪被弹开**：长枪兵进入收枪恢复（`recover` → 非战斗状态）+ 枪被甩向上方（`spearKnock` 0.35s），要重新摆枪（level 0.28s）才能再刺——给剑士贴脸的机会窗口

> 格挡判定在 `applyHit()` 里（目标为剑士且 `BLOCK_CHANCE=0.3`），参数 `BLOCK_TIME=0.5s`。

### 5.7 卡牌召唤 + 伪3D 深度排序 + 软分离

**① 底部卡牌栏（卡牌驱动）**

- 屏幕底部绘制 `CardDef` 卡牌（Graphics 手绘 + 迷你武器图标 + 名称 + 冷却条）
- 点击卡牌 → `spawnFromCard()`：在卡牌上方生成该兵种（尘土 + 名称飘字反馈），0.8s 冷却
- 召唤后自动索敌：`nearestEnemyInRange(u, u.stats.aggro)` 找到最近的敌方单位即进入战斗

**② 伪3D：允许叠加的深度排序（不是纯 2D 边界碰撞）**

- 每帧 `applyDepthSort()`：所有单位按 `pos.y` 升序排，`setDepth(10 + i)`
- 靠屏幕下方的单位（y 大 = 更"近"）绘制在上层 → **一个长枪兵可以覆盖另一个长枪兵**
- 覆盖是自然的遮挡（后方单位的枪/身被前方单位挡住），这就是"叠加式伪3D"

**③ 软分离：避免完全重叠（关键算法）**

```ts
separateUnits(dt)  // 只对同队单位生效（跨队允许贴脸近战）
// 距离 < SEP_MIN(30px) 时，双方沿连线缓慢推开：
step = (SEP_MIN - d) * SEP_RATE * dt   // SEP_RATE = 2.0，指数收敛，不抖动
```

- 推力连续渐变 → "缓慢隔开一点点距离"，不会像硬碰撞那样瞬间弹开
- 完全重叠（同点召唤）也能自动散开成小群
- 同队限制：剑士要贴到敌人脸上近战，跨队不能推开

### 5.8 单位管理规则

**开局**：场上无单位；从底部卡牌召唤兵种（长矛兵 / 剑士），从屏幕左边统一生成。
**单位管理**：框选多个单位，批量控制移动、停止、攻击、处决。

- **① 单位生成**：从屏幕左边50px处统一生成，生成位置一致
- **② 同阵营设置**：长枪兵和剑士都是A阵营，不互相攻击，没有自动索敌
- **③ 框选系统**：左键拖拽框选多个单位，显示绿色框选矩形
- **④ 边界限制**：单位底部边界是卡牌栏，不会进入卡牌栏区域
- **⑤ 批量控制**：框选多个单位后，V/A/K键可以控制所有选中单位
- **⑥ 单位特性**：
  - 长枪兵：攻击距离长、命中击退、首击50%暴击、贴脸后撤步
  - 剑士：移速快、攻击高、血厚、对长枪兵1.5倍伤害加成、30%盾牌格挡

**数值都在 `src/units.ts`**（hp/speed/damage/retreatFactor）与 `DemoScene.ts` 顶部常量，方便调平衡。

## 七、如何加一个新单位（给接手者的指引）

1. 在 `src/art/` 里加 `drawXxx(g, config, anim)`，复用同样的画布变换 + 动画参数接口
2. 在 `src/units.ts` 注册表加一条 `UnitStats`（HP/速度/伤害/武器参数/几何）——**场景逻辑无需改动**
3. 在 `DemoScene` 的 `drawUnit()` / `updateDeath()` 加一个渲染分支（两处 if）
4. 动画状态机是**通用的**——新单位直接复用 `anim.mode` + `combat.phase` 框架
5. 近战武器：定义"握持点 + 武器长度 + 滑枪位"即可，**距离控制/瞄准自动生效**（见 5.3）
6. 想要卡牌召唤：在 `create()` 的 `this.cards` 数组加一行即可

## 八、踩坑与经验（重要，避免重复踩）

1. **Phaser 4 没有默认导出**：必须 `import * as Phaser from 'phaser'`（v3 的 `import Phaser from 'phaser'` 会构建失败）
2. **Graphics 没有 `quadraticCurveTo`**；`fillPoints`/`strokeEllipse`/`fillRoundedRect` 等都在
3. **画布变换**（`save/translateCanvas/scaleCanvas/rotateCanvas/restore`）是"整幅画旋转/镜像"的唯一干净方案，别逐点算坐标
4. **攻击距离 = 武器几何**：单位交战距离必须由"武器尖实际位置"推导，否则出现"贴脸戳空气"的假动作
5. **伪3D 靠深度排序而不是物理碰撞**：同队"允许叠加但软分离"时，分离必须只对同队生效，否则贴脸近战的剑士会被自己的队形推开打不到敌人
6. **卡牌点击判定**：`pointerdown` 里先判卡牌矩形再判单位拾取，卡牌区在最底部不会误选单位
7. **框选边界限制**：框选和移动都要检查卡牌栏边界，避免单位被遮挡
8. **同阵营设置**：修改阵营后要关闭自动索敌（aggro=0），否则单位会寻找不存在的敌人
