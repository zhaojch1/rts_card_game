# AI 出图提示词规范（卡通插画风 · 卡牌 RTS）

> 铁律：**永远不用一句话提示词**。例如"生成一个长枪兵"这种，模型会自由发挥，
> 可能给你一张"在战场上望着日落的背影"——完全没法用。
> 每个提示词必须是**七段齐全**的结构化描述。

## 提示词七段结构

```
[1 角色]    种族/体型/服装/武器/配色 —— 写死存为"角色卡"，跨图逐字复用
[2 姿势]    站姿/朝向/肢体动作/武器持法
[3 构图]    全身入画、居中、占画面高度、无裁剪
[4 背景]    纯白背景、无场景、无地面、无阴影
[5 光线]    均匀正面光
[6 风格]    ★ 固定"风格后缀"（全游戏共用 → 全局风格统一）
[7 质量]    游戏素材、高清、干净边缘
```

## 固定风格后缀（所有角色、所有出图都原样粘贴）

```
卡通渲染风格，圆润Q版角色，粗黑描边，高饱和配色，手机卡牌游戏立绘质感，正面平视视角，全身完整入画，居中构图，角色占画面高度90%，均匀正面光无阴影，干净简洁，高清游戏素材
```

## 固定负面提示词（模型支持负面词时必带）

```
日落，战场背景，风景，背影，侧面，仰视，俯视，动态姿势，动作模糊，多角色，文字，水印，签名，边框，模糊，噪点，写实照片，剪影，透视变形，武器指向镜头，脚部出画，裁剪
```

## 示例：长枪兵（正式可用的完整提示词）

> Q版二头身卡通长枪兵，圆头圆肚皮短四肢：头戴深蓝色圆顶头盔，穿蓝色布甲上衣配深蓝腰带，浅灰色裤子，棕色短靴；双手握一杆长枪（深棕色木杆、银色菱形枪头），枪身斜持于身体右侧；正面站立面朝镜头，双腿分开与肩同宽，站姿稳定；纯白色背景，无地面无阴影；均匀正面光；卡通渲染风格，圆润Q版角色，粗黑描边，高饱和配色，手机卡牌游戏立绘质感，正面平视视角，全身完整入画，居中构图，角色占画面高度90%，均匀正面光无阴影，干净简洁，高清游戏素材

## 一致性三原则

1. **角色卡复用**：角色段写好后存成模板，以后换姿势/换角度**只改姿势段**，角色段逐字不动
2. **风格后缀固定**：所有角色共用同一段风格描述 → 不同单位之间风格统一
3. **选优 + 锚定**：每张图生成 4 张选 1 张最正的，后续该角色所有图以它为参照（参考图/img2img）

## 工作流（一张正式立绘）

1. 复制"示例：长枪兵"整段提示词 → 豆包/即梦出图，一次出 4 张
2. 选 1 张姿势最正、无残缺的
3. 纯白底抠图 → 透明 PNG（免费在线工具或 API）
4. 交给 Rive 做骨骼绑定（idle/walk/attack）
5. 导出 `.riv` → `public/rive/` → 接入游戏
